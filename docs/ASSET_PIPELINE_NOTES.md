# Endesium Asset Pipeline Notes

This document describes how Endesium's textures, models, and other assets are
produced and maintained.

## Texture generation

Most textures are generated procedurally by Python scripts in the `tools/`
folder rather than hand-painted, which keeps the art style consistent across
the large number of blocks and items:

- `gen_eco_textures.mjs` — ecology-themed textures.
- `gen_void_assets.mjs` — Void Skirts block and item textures.
- `gen_eco_item_assets.mjs` — item icons for ecology drops.
- `gen_eco_mob_assets.py` — mob textures.
- `gen_mob_textures.py` — additional mob textures.
- `gen_armor_textures.py` — armor layer textures.
- `gen_ashen_textures.py` — Ashen Expanse textures.
- `gen_dragon_textures.mjs` — dragon and dragon-material textures.
- `gen_biome_assets.mjs` — biome block textures.
- `gen_wings_texture.mjs` — Resonant Elytra wing texture.
- `gen_texture_upgrade.py` — texture refinement pass.

Run a script with `node tools/<script>.mjs` or `python tools/<script>.py` from
the project root. Scripts write directly into
`src/main/resources/assets/endesium/textures/`.

## Models and blockstates

Item models and blockstates live under
`src/main/resources/assets/endesium/models/` and `blockstates/`. Many are
generated by the Fabric datagen model provider; hand-authored ones live
alongside them. Block models are under `models/block/`.

## Previewing assets

- `tools/preview_mob_textures.html` — preview mob textures in a browser.
- `tools/preview_textures_embedded.html` — preview all textures.
- `tools/gen_preview.py` — generate preview sheets.

## Auditing

- `tools/audit_2d_assets.py` — check 2D assets for missing or broken files.
- `tools/audit_mobs.py` — check mob models and textures.
- `tools/check_resources_complete.py` — verify resource completeness.

## Style guidelines

See `docs/ASSET_GUIDELINES.md` and `docs/AUDIO_VISUAL_DESIGN.md` for the
visual language: dark slate tones, gold and cyan accents, and a
resonance-themed glow.
