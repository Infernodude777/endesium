# Endesium Playtesting Guide

This guide explains how to run and test Endesium during development.

## Building the mod

From the project root, run the Gradle wrapper:

```
./gradlew build
```

On Windows use `gradlew.bat build`. The compiled jar lands in `build/libs/`.

## Running a dev client

```
./gradlew runClient
```

This launches a Minecraft client with the mod loaded and a development
workspace. Use the `run/` folder's world for testing — it already contains
structures and biomes from earlier sessions.

## Running datagen

Recipes, loot tables, models, and language entries are generated by the
Fabric datagen providers in `src/client/java/.../datagen/`:

```
./gradlew runDatagen
```

After running datagen, verify the generated files appear in the configured
output directory and that no duplicate resource errors are reported.

## What to test after this pass

1. **Recipes** — open the recipe book and confirm every new recipe appears and
   crafts correctly. Pay special attention to the smelting and blasting
   recipes for Void Ingots.
2. **Advancements** — grant yourself items via `/give` and confirm each new
   advancement triggers, shows a toast, and displays localized text.
3. **Biome tools** — spawn in each biome and confirm the signature tool works
   as intended.
4. **Worldgen** — fly around and confirm the new biomes generate with their
   structures and flora.
5. **Balance** — verify that material costs feel fair and that no recipe is
   trivially cheap or absurdly expensive.

## Reporting issues

Log issues with a screenshot, the game version, and the steps to reproduce.
Include the relevant log lines from `run/logs/latest.log`.
