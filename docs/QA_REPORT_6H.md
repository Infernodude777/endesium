# Endesium QA Report — 6-Hour Session

## Scope

This QA pass covered the crafting and progression additions made during the
six-hour session: 50 new recipes, 15 new advancements, and 10 new
documentation files.

## Build verification

- The project compiles cleanly with `./gradlew compileJava compileClientJava`.
- No duplicate resource errors are introduced: all new recipe and advancement
  IDs are unique.

## Recipe verification

- All 50 new recipes reference only registered items and blocks. Ingredient
  IDs were cross-checked against `ModItems` and `ModBlocks`.
- Smelting and blasting recipes use the correct 1.21.1 result format
  (`"result": { "id": ... }`).
- Alternate recipes (Void Brick from Umbral Stone/Voidstone, etc.) do not
  collide with the datagen-generated recipes.

## Advancement verification

- All 15 new advancements use valid parents (existing endesium advancements or
  vanilla roots).
- Icons reference existing items.
- Every advancement has a matching title/description translation added to the
  language provider.

## Documentation verification

- All 10 new docs are valid Markdown and reference real files, items, and
  systems.
- The crafting reference matches the recipe data files.

## Known limitations

- Raw JSON recipes are not regenerated by datagen; if the datagen recipe
  provider is later extended with the same IDs, the raw files must be removed
  to avoid conflicts.
- The new advancements are not yet exercised in a live client; a playtest
  session is recommended to confirm toasts and localization render correctly.

## Recommendations

1. Run a live playtest to confirm recipe book integration.
2. Consider adding slab/stairs/wall variants for the new stone types in a
  future pass.
3. Update `docs/FEATURE_REFERENCE.md` to include the new recipes and
  advancements.
