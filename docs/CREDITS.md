# Credits

## Author

Endesium is developed by infernodude777.

## Built with

- Minecraft Java Edition 1.21.1.
- Fabric Loader and Fabric API, the modding framework the project is built on.
- Fabric Loom with official Mojang mappings for the build pipeline.
- GeckoLib 4.9.2 for the Void Stalker model, renderer, and animations.
- Blockbench for geometry and animation authoring.
- The Fabric example mod template as the foundation for the project layout.

## Design and assets

The visual language was specified before implementation and documented in the visual design and vertical slice design documents. The palette, material language, and pixel-art rules in those documents are the source of truth for every texture in the mod.

## Tools in the pipeline

- Data generation through the Fabric datagen entrypoint for recipes, loot tables, advancements, and language entries.
- DogSprite for pixel-art authoring and validation of item textures.
- Version control through Git, with the repository hosted on GitHub.

## Inspiration

The mod is inspired by the vanilla End's emptiness and scale, and by the idea that the most interesting discoveries in a game are the ones that do not announce themselves. The design deliberately keeps the End recognizable and adds small, strange things that do not belong.

Thanks to the Fabric and GeckoLib communities for documentation and tooling, and to everyone who tested the first slice and reported how it felt.
