# Endesium Crafting Reference

This document is the authoritative reference for every crafting recipe in
Endesium. Recipes are grouped by progression stage so a player can see at a
glance what to build next.

## Void tools and armor

All Void tools (Sword, Pickaxe, Axe, Shovel, Hoe) are forged from Void Ingots
and sticks in the standard vanilla patterns. Void armor (Helmet, Chestplate,
Leggings, Boots) uses the standard armor patterns with Void Ingots.
